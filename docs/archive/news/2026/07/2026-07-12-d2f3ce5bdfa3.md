Title: Lunar Linux Website 3.2 released

Lunar Linux Website has been promoted to version 3.2.

This release reorganizes the site's information architecture around clearer domain ownership. The former News page becomes Info, the central Archive entry leaves the main navigation, and LUR becomes a first-class destination for community projects.

Archive access is now placed beside the content it preserves: project news links to the News Archive, Moonbase activity links to the Commit Archive, and Documentation provides its own historical archive.

Compatibility redirects keep the former `news.html` and `archive.html` addresses functional while the public navigation moves to the new structure.

Website 3.2 also establishes the architectural baseline for the next phase of generator cleanup: Git and Markdown remain the source of truth, `docs/` remains the public output, and reusable behavior is extracted only where real repetition proves a stable boundary.

> Website 3.2 simplifies navigation by placing information and history where users naturally expect to find them.
